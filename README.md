Differential Counter

A free, bilingual (EN/PT) web tool for practicing manual white blood cell differentials.

👉 Try it: https://thiagowzs.github.io/ContadorDiferencial/

The manual differential is still a core skill in hematology, but practicing it usually means sitting at a microscope with real slides. Differential Counter brings that practice to the browser: it shows real peripheral blood cell images one at a time, and you classify each one with your counter keys, just like at the bench.

Features
1,500 real cell images across 5 classes: neutrophils (segmented and band), lymphocytes, monocytes, eosinophils and basophils
50, 100 or 200-cell rounds, with cell proportions that change every round and always stay within adult reference ranges
Customizable counter keys, so you can practice with the same layout you use at work
Error review at the end of each round, showing which cells went to the wrong key
Round history to track your progress
Your own image sets: load folders of images, and each folder name becomes a counter key
English and Portuguese interface, on desktop and mobile
Disease profiles (hereditary spherocytosis, sickle cell disease, Burkitt lymphoma and others) — in progress

Image file names are hashed at build time, so the URL never gives away the answer.

Built with

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. A small Python script (build.py) prepares the image bank.
